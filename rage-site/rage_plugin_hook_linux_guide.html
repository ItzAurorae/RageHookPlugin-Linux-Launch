Run RAGE Plugin Hook on Linux.

BEFORE YOU START

Requirements

  • A supported Linux desktop distribution.
  • Steam installed and working.
  • GTA V Legacy installed through Steam. Steam AppID: 271590.
  • A Proton compatibility tool selected for GTA V. The tested example uses GE-Proton11-1.
  • RAGE Plugin Hook installed in the GTA V game folder, with RAGEPluginHook.exe present.
  • Python 3 available if you choose the local virtual-environment installation method.
Use the same Steam library, game installation, and compatibility prefix that you use for GTA V. Do not create a separate Wine prefix for this launch method.

DISTRIBUTION SETTINGS

Select your Linux distribution

Choose your operating system to display its package installation instructions. The commands below are for native Steam installations. If you installed Steam through Flatpak, additional setup and permissions may be required.

EndeavourOS

EndeavourOS is based on Arch Linux and uses pacman.

Install system packages
sudo pacman -Syu
sudo pacman -S --needed protontricks python python-pip python-virtualenv

Arch Linux

Arch Linux uses pacman. Protontricks is available through the Arch package repositories.

Install system packages
sudo pacman -Syu
sudo pacman -S --needed protontricks python python-pip python-virtualenv

Ubuntu

Ubuntu uses apt. This option installs Python virtual-environment support and pipx, which installs Protontricks in an isolated Python environment.

Install system packages and Protontricks
sudo apt update
sudo apt install -y python3 python3-pip python3-venv pipx winetricks

pipx ensurepath
pipx install protontricks

Debian

Debian uses apt. pipx keeps Protontricks separate from the system-managed Python environment.

Install system packages and Protontricks
sudo apt update
sudo apt install -y python3 python3-pip python3-venv pipx winetricks

pipx ensurepath
pipx install protontricks

Linux Mint

Linux Mint is Ubuntu-based and uses apt.

Install system packages and Protontricks
sudo apt update
sudo apt install -y python3 python3-pip python3-venv pipx winetricks

pipx ensurepath
pipx install protontricks

Fedora

Fedora uses dnf. Install Protontricks and the supporting Python packages from your enabled repositories.

Install system packages
sudo dnf install -y protontricks python3 python3-pip

openSUSE

openSUSE uses zypper. Package availability can vary between Leap and Tumbleweed and enabled repositories.

Refresh repositories and install packages
sudo zypper refresh
sudo zypper install protontricks python3 python3-pip
Verify the installation: Open a new terminal and run: 
protontricks --version
If the command is not found after using pipx, open a new terminal or add pipx's binary directory to your PATH. If your distribution does not provide the Protontricks package, use the local virtual-environment method in the next section instead.
Flatpak Steam users: These native package commands do not automatically grant Protontricks access to a Flatpak Steam library. Follow the Protontricks Flatpak instructions and make sure the Steam library and compatibility data are accessible to the application.
STEP 1

Confirm your installation paths

The following is a read-only check using the example paths. Change the variables if your Steam library is somewhere else.

Path verification
STEAM="/opt/games/Steam"
GAME="$STEAM/steamapps/common/Grand Theft Auto V"
PREFIX="$STEAM/steamapps/compatdata/271590"
GE="$STEAM/compatibilitytools.d/GE-Proton11-1"

echo "GTA V executable:"
ls -l "$GAME/GTA5.exe"

echo "RAGE Plugin Hook:"
ls -l "$GAME/RAGEPluginHook.exe"

echo "GE-Proton:"
ls -ld "$GE"

echo "Steam compatibility prefix:"
ls -ld "$PREFIX/pfx"
If a path is missing, stop and correct it before continuing. Your Steam library may be installed somewhere else. Common native Steam locations include ~/.local/share/Steam and ~/.steam/steam.
STEP 2

Install Protontricks

Choose one installation method. The local method does not require administrator access. The system-wide method uses the package manager or pipx instructions for your distribution above.

Option A — Local installation (no sudo)

This creates a Python virtual environment in your GTA V folder and installs Protontricks there. It avoids changing system Python packages.

Install Protontricks locally
STEAM="/opt/games/Steam"
GAME="$STEAM/steamapps/common/Grand Theft Auto V"

cd "$GAME" || exit 1

export STEAM_DIR="$STEAM"
export STEAM_COMPAT_DATA_PATH="$STEAM/steamapps/compatdata/271590"

mkdir -p .tools || exit 1

if [ ! -x .tools/protontricks/bin/python ]; then
    python3 -m venv .tools/protontricks || exit 1
fi

.tools/protontricks/bin/python -m pip install --upgrade pip
.tools/protontricks/bin/python -m pip install --upgrade protontricks || exit 1

echo "Checking Protontricks..."
.tools/protontricks/bin/protontricks --version || exit 1
Why a virtual environment? It keeps the Protontricks Python package inside the GTA V directory instead of changing system Python packages. If Python virtual-environment support is missing, install the appropriate Python package using the OS selector above.

Option B — System-wide installation

If you selected a package-manager or pipx installation in the OS selector, use the system-wide Protontricks command for the remaining steps.

Verify system-wide Protontricks
protontricks --version
protontricks-launch --help
Important: Do not mix the local and system-wide methods. If you installed Protontricks locally, use the local executable in the following steps. If you installed it through your distribution or pipx, use protontricks and protontricks-launch.
STEP 3

Set the Wine prefix to Windows 10

Set the Windows version in the GTA V Steam Proton prefix—not in a separate Wine prefix. Close GTA V and RAGE Plugin Hook first. This updates the prefix registry setting used by Wine.

Set Windows 10 in the GTA V prefix
STEAM="/opt/games/Steam"
GE="$STEAM/compatibilitytools.d/GE-Proton11-1"
PREFIX="$STEAM/steamapps/compatdata/271590/pfx"
WINE="$GE/files/bin/wine"
WINESERVER="$GE/files/bin/wineserver"

export WINEPREFIX="$PREFIX"
export WINE="$WINE"
export WINESERVER="$WINESERVER"

"$WINESERVER" -k 2>/dev/null

"$WINE" reg add 'HKCU\Software\Wine' \
  /v Version /t REG_SZ /d win10 /f

"$WINE" reg query 'HKCU\Software\Wine' /v Version
Expected result: The registry query should show Version REG_SZ win10. This changes the Windows-version compatibility setting only; it does not install Windows or replace Proton. If you use a different Steam library or GE-Proton folder, update the paths.
STEP 4

Download and install Microsoft .NET Framework 4.8

RAGE Plugin Hook is a .NET application. This step installs the .NET Framework 4.8 runtime into the same GTA V Proton prefix used by Steam. Do not install .NET into your Linux system or a different Wine prefix.

Official Microsoft download: Download .NET Framework 4.8. Choose the Runtime download, not the Developer Pack. Microsoft also provides an offline installer. The Protontricks command below downloads the required installer automatically, so a separate manual download is normally unnecessary.

Option A — Local Protontricks installation

Install .NET 4.8 in the GTA V prefix
STEAM="/opt/games/Steam"
GAME="$STEAM/steamapps/common/Grand Theft Auto V"
GE="$STEAM/compatibilitytools.d/GE-Proton11-1"

export STEAM_DIR="$STEAM"
export STEAM_COMPAT_DATA_PATH="$STEAM/steamapps/compatdata/271590"
export WINEPREFIX="$STEAM_COMPAT_DATA_PATH/pfx"
export WINE="$GE/files/bin/wine"
export WINESERVER="$GE/files/bin/wineserver"

cd "$GAME" || exit 1

"$GAME/.tools/protontricks/bin/protontricks" \
  --no-bwrap --no-runtime 271590 dotnet48

Option B — System-wide Protontricks installation

Install .NET 4.8 using system Protontricks
STEAM="/opt/games/Steam"
GE="$STEAM/compatibilitytools.d/GE-Proton11-1"

export STEAM_DIR="$STEAM"
export STEAM_COMPAT_DATA_PATH="$STEAM/steamapps/compatdata/271590"
export WINEPREFIX="$STEAM_COMPAT_DATA_PATH/pfx"
export WINE="$GE/files/bin/wine"
export WINESERVER="$GE/files/bin/wineserver"

protontricks --no-bwrap --no-runtime 271590 dotnet48
Important: Close GTA V and RAGE before installing. Keep the terminal open and follow any installer prompts. This modifies the existing compatdata/271590/pfx prefix; it does not reinstall GTA V or delete your mods. If .NET 4.8 is already present, Protontricks may report that it is installed.
STEP 5

Launch RAGE Plugin Hook

After completing the .NET step, use the launch method that matches your Protontricks installation. Both methods use Steam AppID 271590 and the existing GTA V Proton prefix.

Option A — Local Protontricks installation

Launch RAGE Plugin Hook
STEAM="/opt/games/Steam"
GAME="$STEAM/steamapps/common/Grand Theft Auto V"

cd "$GAME" || exit 1

export STEAM_DIR="$STEAM"
export STEAM_COMPAT_DATA_PATH="$STEAM/steamapps/compatdata/271590"

echo "Checking Protontricks..."
"$GAME/.tools/protontricks/bin/protontricks" --version || exit 1

echo "Launching RAGE Plugin Hook..."
"$GAME/.tools/protontricks/bin/protontricks-launch" \
    --appid 271590 \
    --no-bwrap \
    --no-runtime \
    "$GAME/RAGEPluginHook.exe"

Option B — System-wide Protontricks installation

Launch RAGE using system Protontricks
STEAM="/opt/games/Steam"
GAME="$STEAM/steamapps/common/Grand Theft Auto V"

cd "$GAME" || exit 1

export STEAM_DIR="$STEAM"
export STEAM_COMPAT_DATA_PATH="$STEAM/steamapps/compatdata/271590"

protontricks-launch \
    --appid 271590 \
    --no-bwrap \
    --no-runtime \
    "$GAME/RAGEPluginHook.exe"
Keep the terminal open while RAGE starts. If the launcher exits or displays an error, its terminal output can help identify the problem.

Start playing

Wait for RAGE Plugin Hook

TROUBLESHOOTING

Common problems

“No such file or directory”

Your Steam or GTA V path differs from the example, or RAGE Plugin Hook is not installed in the GTA V root. Update the paths and confirm the executable exists.

protontricks-launch: command not found

If you used the local installation, invoke the executable inside .tools/protontricks/bin/. If you used pipx, open a new terminal and check that pipx's binary directory is in your PATH. If you used a distribution package, verify that the package installed successfully.

Python virtual environment creation fails

Make sure Python 3 and virtual-environment support are installed. On Debian-based distributions, this commonly requires the python3-venv package. On Arch-based systems, install Python and the virtual-environment support package.

Protontricks cannot find Steam or GTA V

Confirm that Steam is running and that the Steam library path is correct. If Steam is installed through Flatpak, the Protontricks application may need access to the Flatpak Steam data and game library.

RAGE starts but GTA V does not

Keep the terminal open and inspect its output. Confirm Steam is running, the AppID is correct, and the selected Proton version is installed. Avoid switching prefixes mid-troubleshooting.

Rockstar says Windows 7 or Windows 8 support has ended

In the tested setup, setting Windows 10 in the actual Proton prefix resolved the warning. This is not required for every installation. Do not copy registry commands blindly: first confirm the correct prefix and back up registry settings.

A RAGE plugin or mod fails after the game starts

This may be a plugin compatibility issue rather than a Protontricks launch issue. Test with the base RAGE setup, then add plugins back one at a time. Check each mod's GTA V build and RAGE Plugin Hook compatibility.

Do not delete your Proton prefix as a first troubleshooting step. It can contain Rockstar Launcher data, settings, and dependencies. Back it up before attempting a prefix rebuild.

What this guide does

  • Uses the existing Steam GTA V prefix.
  • Provides distribution-specific Protontricks installation instructions.
  • Supports a local Python virtual-environment installation.
  • Launches RAGEPluginHook.exe with Protontricks and AppID 271590.
  • Uses --no-bwrap and --no-runtime in the example commands.

What this guide cannot guarantee

  • Every Linux distribution or Proton release will work.
  • Every RAGE plugin, LSPDFR plugin, or GTA V mod is Linux-compatible.
  • Online services or anti-cheat-protected modes will work.
  • Future GTA V updates will preserve compatibility.
  • Every Steam library will use the same installation paths.
