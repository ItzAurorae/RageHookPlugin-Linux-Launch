Run RAGE Plugin Hook on Linux.

A practical guide based on a working EndeavourOS + Steam + GE-Proton setup. It uses Protontricks to start RAGEPluginHook.exe inside the same compatibility prefix as your Steam copy of GTA V.

BEFORE YOU START

Requirements

  • A Linux desktop distribution (this example uses EndeavourOS).
  • Steam installed and working.
  • GTA V Legacy installed through Steam. Steam AppID: 271590.
  • A Proton compatibility tool selected for GTA V. The tested example uses GE-Proton11-1.
  • RAGE Plugin Hook installed in the GTA V game folder, with RAGEPluginHook.exe present.
  • Python 3 available on the system.
Use the same Steam library, game installation, and compatibility prefix that you use for GTA V. Do not create a separate Wine prefix for this launch method.

STEP 1

Confirm your installation paths

Run this read-only check in a terminal.

Path verification
STEAM="/opt/games/Steam"
GAME="$STEAM/steamapps/common/Grand Theft Auto V"
PREFIX="$STEAM/steamapps/compatdata/271590"
GE="$STEAM/compatibilitytools.d/GE-Proton11-1"

echo "GTA V executable:"
ls -l "$GAME/GTA5.exe"
echo "RAGE Plugin Hook:"
ls -l "$GAME/RAGEPluginHook.exe"
echo "GE-Proton:"
ls -ld "$GE"
echo "Steam compatibility prefix:"
ls -ld "$PREFIX/pfx"
If a path is missing, stop and correct it before continuing. Your Steam library may be installed somewhere else.
STEP 2

Non-Sudo Install (Recommended)

Recommended if you do not want to use sudo or change system packages. This creates a Python virtual environment in the GTA V folder, installs Protontricks there, and checks that it runs.

Install Protontricks locally without administrator access
cd "/opt/games/Steam/steamapps/common/Grand Theft Auto V" || exit 1

export STEAM_DIR="/opt/games/Steam"
export STEAM_COMPAT_DATA_PATH="/opt/games/Steam/steamapps/compatdata/271590"

mkdir -p .tools || exit 1

if [ ! -x .tools/protontricks/bin/python ]; then
    python -m venv .tools/protontricks || exit 1
fi

.tools/protontricks/bin/python -m pip install --upgrade protontricks || exit 1

echo "Checking Protontricks..."
.tools/protontricks/bin/protontricks --version || exit 1
Why a virtual environment? It keeps the Protontricks Python package inside the GTA V directory instead of changing system Python packages.
Alternative: Sudo Install (System-Wide)

Choose this if you want Protontricks installed for all users through your Linux distribution's package manager. The command below is for Arch Linux and EndeavourOS. It installs the distribution package system-wide and will ask for your administrator password.

Install Protontricks system-wide (Arch / EndeavourOS)
sudo pacman -Syu protontricks

echo "Checking system Protontricks..."
protontricks --version

For other distributions: install Protontricks using your distribution's supported package manager, then verify with protontricks --version. Package names and commands may differ.

Important: Do not run both installation methods unless you intentionally want two separate installations. Pick one method and use its Protontricks executable in the .NET and launch steps below.

STEP 3

Set the Wine prefix to Windows 10

Set the Windows version in the GTA V Steam Proton prefix—not in a separate Wine prefix. Close GTA V and RAGE Plugin Hook first. This updates the prefix registry setting used by Wine.

Set Windows 10 in the GTA V prefix
STEAM="/opt/games/Steam"
GE="$STEAM/compatibilitytools.d/GE-Proton11-1"
PREFIX="$STEAM/steamapps/compatdata/271590/pfx"
WINE="$GE/files/bin/wine"
WINESERVER="$GE/files/bin/wineserver"

export WINEPREFIX="$PREFIX"
export WINE="$WINE"
export WINESERVER="$WINESERVER"

"$WINESERVER" -k 2>/dev/null
"$WINE" reg add 'HKCU\Software\Wine' \
  /v Version /t REG_SZ /d win10 /f

"$WINE" reg query 'HKCU\Software\Wine' /v Version
Expected result: The registry query should show Version REG_SZ win10. This changes the Windows-version compatibility setting only; it does not install Windows or replace Proton. If you use a different Steam library or GE-Proton folder, update the paths.
STEP 4

Download and install Microsoft .NET Framework 4.8

RAGE Plugin Hook is a .NET application. This step installs the .NET Framework 4.8 runtime into the same GTA V Proton prefix used by Steam. Do not install .NET into your Linux system or a different Wine prefix.

Official Microsoft download: Download .NET Framework 4.8. Choose the Runtime download, not the Developer Pack. Microsoft also provides an offline installer. The Protontricks command below downloads the required installer automatically, so a separate manual download is normally unnecessary.

Download and install .NET 4.8 in the GTA V prefix
STEAM="/opt/games/Steam"
GAME="$STEAM/steamapps/common/Grand Theft Auto V"
GE="$STEAM/compatibilitytools.d/GE-Proton11-1"

export STEAM_DIR="$STEAM"
export STEAM_COMPAT_DATA_PATH="$STEAM/steamapps/compatdata/271590"
export WINEPREFIX="$STEAM_COMPAT_DATA_PATH/pfx"
export WINE="$GE/files/bin/wine"
export WINESERVER="$GE/files/bin/wineserver"
export PATH="/opt/games/Steam/protontricks-work/bin:$PATH"

cd "$GAME" || exit 1

"$GAME/.tools/protontricks/bin/protontricks" \
  --no-bwrap --no-runtime 271590 dotnet48
If you chose Sudo Install: use the system-wide Protontricks command instead of the local virtual-environment executable. Run this alternative .NET install command:
.NET 4.8 using system-wide Protontricks
STEAM="/opt/games/Steam"
GE="$STEAM/compatibilitytools.d/GE-Proton11-1"

export STEAM_DIR="$STEAM"
export STEAM_COMPAT_DATA_PATH="$STEAM/steamapps/compatdata/271590"
export WINEPREFIX="$STEAM_COMPAT_DATA_PATH/pfx"
export WINE="$GE/files/bin/wine"
export WINESERVER="$GE/files/bin/wineserver"

protontricks --no-bwrap --no-runtime 271590 dotnet48
Important: Close GTA V and RAGE before installing. Keep the terminal open and follow any installer prompts. This modifies the existing compatdata/271590/pfx prefix; it does not reinstall GTA V or delete your mods. If .NET 4.8 is already present, Protontricks may report that it is installed.
STEP 5

Launch RAGE Plugin Hook

After completing the .NET step above, use this launch method in the example setup. It uses Steam AppID 271590 and launches RAGE in the existing GTA V Proton prefix.

Working RAGE Plugin Hook launch command
cd "/opt/games/Steam/steamapps/common/Grand Theft Auto V" || exit 1

export STEAM_DIR="/opt/games/Steam"
export STEAM_COMPAT_DATA_PATH="/opt/games/Steam/steamapps/compatdata/271590"

mkdir -p .tools || exit 1

if [ ! -x .tools/protontricks/bin/python ]; then
    python -m venv .tools/protontricks || exit 1
fi

.tools/protontricks/bin/python -m pip install protontricks || exit 1

echo "Checking Protontricks..."
.tools/protontricks/bin/protontricks --version || exit 1

echo "Launching RAGE Plugin Hook..."
.tools/protontricks/bin/protontricks-launch \
    --appid 271590 \
    --no-bwrap \
    --no-runtime \
    "$PWD/RAGEPluginHook.exe"
Keep the terminal open while RAGE starts. If the launcher exits or displays an error, its terminal output can help identify the problem.
If you chose Sudo Install: use this launch alternative, which calls the system-wide protontricks-launch command.
Launch RAGE with system-wide Protontricks
cd "/opt/games/Steam/steamapps/common/Grand Theft Auto V" || exit 1

export STEAM_DIR="/opt/games/Steam"
export STEAM_COMPAT_DATA_PATH="/opt/games/Steam/steamapps/compatdata/271590"

protontricks-launch --appid 271590 --no-bwrap --no-runtime "$PWD/RAGEPluginHook.exe"

TROUBLESHOOTING

Common problems

“No such file or directory”

Your Steam or GTA V path differs from the example, or RAGE Plugin Hook is not installed in the GTA V root. Update the paths and confirm the executable exists.

protontricks-launch: command not found

Run the installation command again. The launcher is invoked from .tools/protontricks/bin/, not from the system PATH.

Python virtual environment creation fails

Make sure Python 3 and virtual-environment support are installed. Package names vary by distribution.

RAGE starts but GTA V does not

Keep the terminal open and inspect its output. Confirm Steam is running, the AppID is correct, and the selected Proton version is installed. Avoid switching prefixes mid-troubleshooting.

Rockstar says Windows 7 or Windows 8 support has ended

In the tested setup, setting Windows 10 in the actual Proton prefix resolved the warning. This is not required for every installation. Do not copy registry commands blindly: first confirm the correct prefix and back up registry settings.

A RAGE plugin or mod fails after the game starts

This may be a plugin compatibility issue rather than a Protontricks launch issue. Test with the base RAGE setup, then add plugins back one at a time. Check each mod's GTA V build and RAGE Plugin Hook compatibility.

Do not delete your Proton prefix as a first troubleshooting step. It can contain Rockstar Launcher data, settings, and dependencies. Back it up before attempting a prefix rebuild.

What this guide does

  • Uses the existing Steam GTA V prefix.
  • Installs Protontricks into a local Python virtual environment.
  • Launches RAGEPluginHook.exe with Protontricks and AppID 271590.
  • Uses --no-bwrap and --no-runtime, matching the tested command.

What this guide cannot guarantee

  • Every Linux distribution or Proton release will work.
  • Every RAGE plugin, LSPDFR plugin, or GTA V mod is Linux-compatible.
  • Online services or anti-cheat-protected modes will work.
  • Future GTA V updates will preserve compatibility.
